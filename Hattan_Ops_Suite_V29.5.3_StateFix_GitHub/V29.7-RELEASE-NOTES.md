# Hattan Ops Suite V29.6–V29.7

## V29.6 — Customer directory
- Customer List loads the full CleanBase directory (`legacy-v296/customer-directory.json`: 27,574 customers; names, addresses and phones for the 4,126 on the 09/01/23–09/28/26 Customer List). It is read-only and never saved to the browser or synced, which fixes the stuck "Loading customer directory…" and the ~300-customer list.
- A CleanBase customer is added to the live customer list only when opened (from Customers or Drop Off search).
- Drop Off search also finds CleanBase customers.
- Balances: completed CleanBase tickets count as settled; each customer's CleanBase account balance (vCust CU98Y, as of 9/18/26) is a "balance forward" line; CleanBase credits become store credit.
- Replaces `v29.4-full-cleanbase.js`, `v29.5-customer-master.js`, `v29.5.2-customer-data.js`, `v29.5.3-customer-load-fix.js` in `index.html` (files kept for rollback).

## V29.7 — Batch charge cards on file
- Payments screen: charge every unpaid card-on-file ticket for **Today** or **All unpaid up to today**, with per-ticket untick, 30-day-old warning and a declined list. Manager only.
- Uses the existing `clover-charge` function (server re-checks ticket + 3% fee, per-ticket idempotency, refuses already-paid/charged tickets).

## Clover settings (Netlify environment variables)
`CLOVER_ENVIRONMENT`, `CLOVER_MERCHANT_ID`, `CLOVER_PUBLIC_TOKEN`, `CLOVER_PRIVATE_TOKEN` (secret). Values are needed in both Production and Deploy Previews contexts. Settings take effect on the next deploy.
