# Hattan Ops Suite V29.5.3 — Customer State/Loader Fix

- Fixes the root cause of the endless customer-directory loading screen.
- The base app declares `state` with top-level `const`; browsers do not expose that lexical binding as `window.state`.
- Previous V29.4/V29.5 loaders incorrectly waited for `window.state`, so customer installation could loop forever even though the bundled data had loaded.
- V29.5.3 explicitly exposes the app state and hardens all customer loaders to use the lexical state safely.
- Keeps the V29.5.2 bundled 27,533-customer CleanBase snapshot and V29.5 identity overlay.
- Adds a 15-second visible failure state instead of an endless spinner.
